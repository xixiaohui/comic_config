# User - comic-manager 用户上下文与项目配置

## 项目基础信息

### 项目名称
**《父与女》四格漫画 IP - 运营管理部门**

### 运营目标
通过高效协调三个创作 agent，实现日更四格漫画的稳定输出，持续扩大 IP 影响力。

---

## 发布计划

### 日常发布节奏
- 每日发布时间：19:00-20:00
- 每日发布数量：1-2 条
- 平台优先级：微信公众号 > 微博 > 抖音

### 内容节奏规划
- 周一/四：成长突破类
- 周二/五：温暖治愈类
- 周三/六：趣事互怼类
- 周日：教育反转类

---

## KPI 监控指标

### 生产指标
- 日更完成率目标：> 95%
- 生产周期目标：< 2 小时
- 质量合格率目标：> 90%

### 传播指标
- 单条阅读量目标：> 10,000
- 分享率目标：> 5%
- 粉丝月增长率：> 10%

---

## 危机处理预案

### P1 级（立即处理）
- 所有 agent 停止响应
- 发布内容出现严重错误

### P2 级（1 小时内）
- 单个 agent 故障
- 质量持续不达标

### P3 级（当日内）
- 数据异常波动
- 读者负面反馈增多

---

## 运营周期

- 日报：每日 21:30 生成
- 周报：每周日 22:00 生成
- 月报：每月最后一天 22:00 生成

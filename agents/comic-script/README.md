# comic-script - 《父与女》脚本编写助手

**Status**: Active | **Version**: 1.0.0 | **Role**: Script Director

## 📋 简介

comic-script 是《父与女》四格漫画 IP 的脚本编导。它负责：

- 📖 接收 comic-topic 提供的高质量选题
- 🎬 将选题转化为视觉化的四格漫画脚本
- 🎨 提供详细的画面指导和艺术建议
- ✨ 确保故事清晰、节奏流畅、画面富有冲击力

## 🎯 核心职责

| 职责 | 说明 |
|------|------|
| 选题转化 | 将选题转化为可执行的四格漫画脚本 |
| 脚本编写 | 编写结构化的脚本 JSON，包含所有画面信息 |
| 视觉指导 | 提供详细的构图、表情、动作、色彩建议 |
| 质量把控 | 确保脚本质量评分 > 8.5 |
| 协作管理 | 与 comic-draw 沟通反馈，快速调整 |

## 🚀 快速开始

### 首次运行
```bash
# 1. 验证所有文件都已就位
ls -la agents/comic-script/

# 2. 加载 comic-script agent
openclaw agents add comic-script ./agents/comic-script

# 3. 启动定时审核任务
openclaw heartbeat start comic-script

# 4. 首次测试：接收 comic-topic 的选题并生成脚本
openclaw chat --agent comic-script "根据选题生成脚本"
```

## 📊 脚本质量评分

- 视觉清晰度：画面是否清晰、主体是否突出
- 故事流畅性：节奏是否流畅、逻辑是否完整

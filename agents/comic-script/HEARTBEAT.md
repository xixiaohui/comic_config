# Heartbeat - comic-script 定时任务清单

## 心跳任务概述
comic-script 通过定期的审核和优化保持活力。

## 日度任务 (DAILY @ 09:30)
触发时间: 每日上午 09:30
预计耗时: 10-15 分钟

### 任务清单
```
[09:30] DAILY REVIEW START
  ├─ 检查是否有 comic-draw 的反馈
  ├─ IF 有问题反馈:
  │   ├─ 分析问题原因
  │   ├─ 修改脚本
  │   └─ 重新发送
  ├─ 验证今日脚本是否都已转化为漫画
  ├─ 统计今日脚本数量和质量
  └─ 更新 MEMORY.md 日志
[09:45] END
```

## 周度任务 (WEEKLY @ MON 15:00)
触发时间: 每周一下午 15:00
预计耗时: 30-45 分钟

### 任务清单
```
[15:00] WEEKLY ANALYSIS START
  ├─ 收集本周所有脚本
  ├─ 计算脚本质量平均分
  ├─ 分析高分脚本特征
  ├─ 分析低分脚本原因
  ├─ 优化脚本模板
  ├─ 更新脚本库
  └─ 生成周度报告
[15:45] END
```

## 月度任务 (MONTHLY @ 1ST 10:00)
触发时间: 每月 1 日上午 10:00
预计耗时: 60 分钟

### 任务清单
```
[10:00] MONTHLY REVIEW START
  ├─ 汇总本月所有脚本数据
  ├─ 评估脚本质量总体水平
  ├─ 分析脚本转化率和修改率
  ├─ 评估 comic-draw 的满意度
  ├─ 制定下月改进计划
  └─ 生成月度报告
[11:00] END
```

记住: 定时审核是保证脚本质量的关键。💫

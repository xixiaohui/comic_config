# User - comic-draw 用户上下文与项目配置

## 项目基础信息

### 项目名称
**《父与女》四格漫画 IP - 漫画绘制部门**

### 画风定义
温暖治愈系日漫风格，色彩明亮，线条简洁，情感丰富。

---

## 角色视觉设定

### 父亲（爸爸）视觉规范
- **发色**: 深棕色短发
- **眼睛**: 温柔的棕色杏眼
- **肤色**: 健康小麦色
- **身高**: 175cm
- **体型**: 中等偏瘦，肩膀宽
- **标志性元素**: 温柔笑容，略显凌乱的发梢

### 七七（女儿）视觉规范
- **发色**: 黑色，扎双马尾
- **眼睛**: 大而圆的黑色眼睛
- **肤色**: 白皙粉嫩
- **身高**: 110-120cm（随季节增长）
- **体型**: 小巧圆润
- **标志性元素**: 双马尾、小虎牙、圆眼睛

---

## 画面构图规范

### 四格布局标准
```
┌─────────────────┐
│    Panel 1      │  铺垫（中景/远景）
├─────────────────┤
│    Panel 2      │  发展（中景/近景）
├─────────────────┤
│    Panel 3      │  高潮（近景/特写）
├─────────────────┤
│    Panel 4      │  收尾（根据情感需要）
└─────────────────┘
```

### 对白气泡规范
- 对话气泡：圆角矩形，白底黑字
- 心理独白：云朵形，淡色背景
- 感叹：锯齿形，强调色

---

## 色彩方案

### 主色调
- 暖白：背景主色 #FFF8F0
- 暖橙：温暖场景 #FF8C42
- 暖黄：快乐场景 #FFD166
- 天蓝：平静场景 #06D6A0

### 情感色彩
- 温暖：橙黄色系
- 安静：蓝绿色系
- 紧张：暗红/灰色系
- 喜悦：明亮彩虹色

---

## 质量标准

- **线条**: 流畅清晰，粗细有变化
- **色彩**: 统一和谐，不超过 5 种主色
- **表情**: 夸张但自然，符合情境
- **构图**: 平衡美观，引导视线
- **文字**: 清晰可读，大小适中

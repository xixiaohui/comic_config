# Heartbeat - comic-draw 定时任务清单

## 心跳任务概述
comic-draw 通过定期检查和质量维护保持创作活力。

## 日度任务 (DAILY @ 10:00)
触发时间: 每日上午 10:00
预计耗时: 15-20 分钟

### 任务清单
```
[10:00] DAILY DRAW REVIEW START
  ├─ 检查是否有新脚本待绘制
  ├─ IF 有新脚本:
  │   ├─ 解析脚本内容
  │   ├─ 开始绘制流程
  │   └─ 输出图像文件
  ├─ 检查昨日漫画反馈
  ├─ 更新角色参考库
  └─ 更新 MEMORY.md
[10:20] END
```

## 周度任务 (WEEKLY @ TUE 14:00)
触发时间: 每周二下午 14:00
预计耗时: 45-60 分钟

### 任务清单
```
[14:00] WEEKLY QUALITY REVIEW START
  ├─ 收集本周所有漫画
  ├─ 统计质量评分
  ├─ 分析高分漫画特征
  ├─ 更新角色参考图库
  ├─ 优化绘制模板
  └─ 生成周度质量报告
[15:00] END
```

## 月度任务 (MONTHLY @ 2ND 10:00)
触发时间: 每月 2 日上午 10:00
预计耗时: 90 分钟

### 任务清单
```
[10:00] MONTHLY REVIEW START
  ├─ 汇总本月绘制数据
  ├─ 评估角色演进情况
  ├─ 优化画风一致性
  ├─ 制定下月创作计划
  └─ 生成月度报告
[11:30] END
```

记住: 每一幅漫画都是 IP 的重要组成部分。💫
